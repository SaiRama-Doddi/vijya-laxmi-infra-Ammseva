# Infra Vision Pro

# Build a premium, fully responsive static corporate website for **Vijaya Lakshmi Infra**, an Electrical & Civil Infrastructure company specializing in Transmission & Distribution (T&D), substations, HT/LT power lines, utility shifting, civil infrastructure, and engineering solutions across India.

The website should look like a ₹40,000+ premium corporate engineering website with smooth animations, modern UI, infrastructure photography, glassmorphism cards, blue gradient sections, and clean typography.
